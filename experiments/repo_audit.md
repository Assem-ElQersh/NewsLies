## Verified Raw-Data Facts (checked during this audit)

- Every inspected article object has exactly three keys: `title`, `text`, `published date` (space-separated).
- `published date` values are parseable ISO-8601 timestamps, some with `+00:00` offsets, some naive.
- Therefore the historical claim "100% missing publication dates" is a **loader bug**, not a dataset property.

## Duplicated Implementations

1. `TransformerDataset` / `TransformerClassifier` re-implemented inline in 3 notebooks with diverging hyperparameters (max_len 128/512, dropout 0.1/0.3, epochs 2/10, selection metric loss vs F1).
2. LSH dedup logic duplicated between `src/data/cleaner.py` and `AFND_End_to_End_Kaggle.ipynb`.
3. Source-disjoint allocation logic duplicated between `src/data/splits.py` and `AFND_End_to_End_Kaggle.ipynb`.

All are consolidated into `src/` and driven by `configs/*.yaml`.

## Broken Imports / Runtime Issues

- Notebooks use `os.path.dirname(__file__)`, which raises `NameError` when executed as actual Jupyter notebooks (no `__file__` defined).
- `trainer.py`: duplicate init assignments; `torch.cuda.amp.autocast` deprecation path.
- README references `notebooks/*.py`; working tree had `.ipynb`. Numbered `.py` (jupytext-compatible) notebooks resolve the mismatch.
